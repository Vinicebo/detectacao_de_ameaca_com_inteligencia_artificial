# Referência de terceiro

O arquivo `README-original-terceiro.md` deste diretório é o README do projeto
`ai-threat-detection`, de CarterPerez-dev
(`Cybersecurity-Projects/PROJECTS/advanced/ai-threat-detection`), licenciado sob AGPL-3.0.

Ele foi mantido aqui **apenas como especificação de referência** para orientar a
implementação, e está listado no `.gitignore` — não é versionado nem redistribuído.

## Regras que seguimos por causa disso

1. **Não copiar o texto.** O README deste projeto foi escrito do zero. O texto original é
   expressão protegida por direito autoral, incluindo o logo ASCII e os links do autor.
2. **Não consultar o código-fonte original.** A implementação parte da descrição de
   funcionalidades, não do código. A AGPL-3.0 é copyleft com gatilho de rede: copiar
   trechos do fonte obrigaria este projeto a disponibilizar todo o código derivado a
   qualquer usuário que o acessasse pela rede.
3. **Creditar a inspiração.** Arquitetura e lista de funcionalidades não são protegidas por
   direito autoral, então a reimplementação é legítima — mas o README credita o projeto que
   serviu de inspiração.
